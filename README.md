### Data 
We use the AMSR2-REMSS-L3U-v8a dataset provided by Remote Sensing Systems for this project. The dataset is available on NASA’s Physical Oceanography Distributed Active Archive Center (PO.DAAC).
We use the data from 2022 and focus on the marine areas around Europe. Each observation contains measurements at a specific location. The location is defined by latitude and longitude, and each observation has its corresponding time.
